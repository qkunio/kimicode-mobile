# KIMI CODE for iOS

在手机上接管电脑里的 Kimi Code。

电脑上跑一条 `kimi rc`，手机上用同一个 Kimi 账号登录，就能从 App 里给电脑上的
Kimi Code 派活：发任务、看它一边思考一边干活、批准或拒绝它要执行的命令、随时叫停。
官方网页端能做的事，这里用 iOS 原生界面做了一遍 —— 不是网页套壳。

> 目前是自行编译安装（源码仓库），没有上架 App Store。

---

## 开始之前

你需要三样东西：

1. **一个 Kimi 账号，GO 及以上订阅** —— 远程控制是付费能力，免费账号登录后拿不到设备。
2. **一台装了 Kimi Code 的电脑**，并且这台电脑要保持开机、联网、不休眠。
3. **iPhone，iOS 26 或更新**。

手机和电脑必须是**同一个 Kimi 账号**，不需要在同一个局域网 —— 连接走 Kimi 官方中转
（`code-rc.kimi.com`），在外面用蜂窝网络一样能连。

### 让电脑待命

在电脑上打开终端，进入你想让 Kimi 干活的项目目录，运行：

```bash
kimi rc
```

终端里会打出一个二维码和链接 —— **App 用不上它们，不用扫也不用复制**，看到进程跑起来就行。
把这个终端窗口留着别关：关掉、`Ctrl+C`、电脑休眠或断网，手机这边立刻就连不上了。

一台电脑同时只能跑一个 `kimi rc`；一个账号大约可以挂 3 台设备。

## 安装到手机

仓库里是 Xcode 工程，自己编译装上去：

```bash
git clone https://github.com/qkunio/kimicode-mobile.git
cd kimicode-mobile
open KimiCode.xcodeproj
```

- 需要 **Xcode 26.2 或更新**（iOS 26.2 SDK）。
- 装到**真机**：在 `KimiCode` target 的 Signing & Capabilities 里选你自己的开发者账号；
  或者建一个 `Config/Local.xcconfig` 写上 `DEVELOPMENT_TEAM = 你的TeamID`（该文件已被 gitignore）。
- 只想在**模拟器**里看看：什么都不用配，直接选个 iPhone 模拟器按 ⌘R。

命令行构建：

```bash
xcodebuild -project KimiCode.xcodeproj -scheme KimiCode -sdk iphonesimulator \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro' -configuration Debug build
```

用免费 Apple ID 签名的话，App 大约 7 天后会过期，重新装一次即可。

## 第一次使用

1. 打开 App，点「**开始使用**」，再点「**登录**」。
2. 系统会弹一句「"KimiCode"想要使用"kimi.com"登录」—— 这是 iOS 的标准提示，点继续。
3. 浏览器里出现 Kimi 的确认页，点确认授权。
4. 浏览器自动收起，直接进入主界面。

没有验证码要抄，没有倒计时要赶，也不用扫码或粘贴链接。
登录凭证存在系统钥匙串里，之后打开 App 直接就是登录状态。

如果你中途自己把浏览器关掉了，App 会再确认一次；确实没授权成功的话回到「登录」按钮，再点一次就行。

## 界面怎么用

### 主页

中间是对话，底部是输入框。输入框上那一排：

| 按钮 | 作用 |
|---|---|
| **+** | 加图片或文件一起发 |
| **⚡︎ 图标** | 权限模式。`hand.raised` = 始终询问，`checkmark.shield` = 必要时询问，`bolt.shield` = 完全自动 |
| **K3·Low** | 模型和思考强度，点开切换（只列 Kimi 官方订阅的模型） |
| **↑** | 发送。任务在跑的时候它变成 **■**，点一下就是中断 |

任务执行时正文里会实时长出内容：思考过程、读了哪些文件、跑了哪些命令，连续的操作会折叠成
「已工作 X 分钟」一行，点开能看全。

右上角的 **⋯** 里是这个会话的上下文占用，以及你账号的**剩余用量**（5 小时 / 每周 / 每月，有哪项显示哪项）。

### 侧栏

从左边缘往右划，或点左上角 **≡**。里面按顺序是：

- **设备** —— 点一下切换电脑，离线的会灰掉点不了。
- **项目文件夹** —— 点名字展开/收起里面的会话，点右边 **+** 在这个文件夹里开新对话。
  新对话是草稿，要等你发出第一条消息才真的建出会话，不会留下一堆空会话。
- **添加项目** —— 浏览电脑上的目录，一级级点进去，或者在当前目录下搜，选中「打开此文件夹」。
  加完会直接在新项目里开一个对话。
- **底部头像** —— 你的昵称，右边是退出登录（会二次确认）。

登录后 App 会自动连上次那台电脑（不在线就换第一台在线的），并打开最近用的文件夹。

### 权限确认

当 Kimi 要跑一条命令、改一个文件、访问一个网址时，对话里会出现一张确认卡片，写清楚它想干什么，
你点同意或拒绝。卡片类型和网页端一致：命令、写文件、diff、访问链接、调用子 agent、待办清单、方案评审。

如果你在电脑上、或者另一台设备上已经点过了，手机这边的卡片会自动消失。

## 已知限制

- 电脑休眠、断网、或者 `kimi rc` 被关掉 → 手机立刻断连，恢复后需要重新在电脑上跑起来。
- 一台电脑只能跑一个 `kimi rc`，一个账号约 3 台设备。
- 必须是付费订阅，且手机电脑同账号。
- 传文件单个上限 9 MB；图片会自动压到长边 1600px；模型不支持读图时 + 菜单里的图片选项会禁用。
- 本轮任务在跑的时候不能再发下一条（不排队），只能等它跑完或者中断。
- 不支持斜杠命令。
- 不能脱离会话浏览电脑的整个文件系统，只能看会话里出现的文件，和添加项目时允许浏览的目录。

### 还没做的

子 agent / task 面板、diff 与文件卡片、终端流、待确认时的推送通知、长任务的灵动岛进度、代码语法高亮。

## 遇到问题

**登录后设备列表是空的**
电脑上的 `kimi rc` 没跑起来，或者电脑登录的不是同一个 Kimi 账号。在电脑上跑 `kimi login` 确认一下账号。

**设备显示离线**
电脑睡了、网断了，或者 `kimi rc` 的窗口被关了。回电脑上重新跑一遍。

**登录一直转圈 / 浏览器打不开**
把 App 划掉重开，重新点登录。授权码会留着复用，重试不会有副作用。

**消息错乱或者丢了**
一般是断网重连没接上。退出会话再进一次，会重新拉一遍正文。

**过一段时间自动退出登录了**
登录凭证有效期约 30 天，App 会在过期前自动续，但如果手机很久没开过 App 就可能来不及。重新登录即可。

## 隐私

- 登录凭证只写入 iOS 钥匙串，不进 UserDefaults，不打日志。
- 账号信息只读取昵称和头像，其它字段（手机号等）不解析、不保存。
- App 只和 Kimi 官方中转通信，不连任何第三方服务；你的代码和对话不经过本项目作者的任何服务器。
- 退出登录会清掉本机所有凭证。

> 跑着 `kimi rc` 的电脑，相当于把一个能执行命令的入口开在了网上。别在不属于你的机器上开，
> 也别把终端里打出的那个链接发给别人。
